# Contributing to CSH
Hello! We love contributions, members who contribute are the best!

In general, checkout the repository's [README.md](README.md) for specific instructions on 
how to setup and run a service locally so that you can make your super cool awesome changes!

After making your changes, please test as much as possible because we don't want to have broken code, and it's easier for everyone if
you realize bugs before someone else goes to test it too

In general, AI use is okay if it's limited, but as an org of computer nerds for computer nerds, we feel that most of our code should be written 
by us. 
Basically, don't vibe code a service or a major change. Ultimately code you submit is owned by you and you should understand it and be able to explain or defend it :)
